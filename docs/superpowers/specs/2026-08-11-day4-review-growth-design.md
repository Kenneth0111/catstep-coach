# CatstepCoach Day 4：逾期调整、复盘、记忆与成长设计

## 目标

在 Day 3 已确认且可执行的今日计划之上，完成不惩罚中断的 Day 4 闭环：用户可处理未完成任务、查看晚间复盘、确认长期记忆，并获得可解释的成长值。

## 范围与顺序

1. `review-generate`：只读取当前认证用户当天的计划与任务结果，生成结构化复盘；模型不可用时返回规则复盘。
2. `review-confirm`：用户确认后保存复盘与可选记忆，并以请求 ID 保证幂等。
3. 成长：仅在首次确认复盘时按确定性规则累计正向成长值，不因未完成任务扣减。
4. 逾期调整：用户可对本人当天待开始任务选择缩小或移至当前计划队尾；缩小操作调用独立的 `resizeTask` 工作流，并保留规则降级。当前数据模型没有跨日期计划，故“移到明天”不在本切片实现。
5. Today UI：在任务完成或当日计划结束后提供复盘入口、加载/错误/确认状态及成长结果。

订阅提醒、额度、日志、自动化部署和真机验收不属于 Day 4。

## 边界

- 所有云函数先从可信 `WX_OPENID` 取得身份；客户端不能传入 owner、日期、成长值或持久化状态。
- `review-generate` 只接受当日计划标识（或空输入以使用服务端当天计划），服务端按 `_openid` 查询，绝不跨用户读取。
- 复盘输出包含完成概览、温和总结、次日起步建议和最多一条记忆候选；不包含诊断、治疗或贬低性话术。
- 模型失败、超时或结构异常时使用确定性的规则复盘；生成不写入数据库。
- `review-confirm` 使用请求 ID 原子保存；相同请求重放返回既有结果，成长值只累计一次。
- 成长值为确定性规则：完成晚间复盘最多增加 10 点；当日累计上限为 70 点（5 项任务、5 次难度反馈与 1 次复盘的 MVP 理论最大值），中断或未完成任务不扣分。

## 首个切片：复盘生成

新增 `review-generate` 云函数及其纯服务模块。测试先覆盖：本人计划的成功生成、缺少计划或外部计划的拒绝、AI 失败时的规则降级、未认证与经过净化的内部错误。随后接入最小部署入口。此切片不提前实现复盘确认、记忆或成长写入。

## 验收标准

1. 已认证用户只能为本人当天计划取得结构化复盘。
2. 复盘给出完成概览、温和总结与一项次日起步建议；生成失败仍可得到可用规则复盘。
3. 复盘确认、记忆和成长写入按用户隔离并可幂等重放，未完成任务不造成扣分。
4. 逾期调整只作用于本人当天未完成任务，且有规则降级路径。
5. 每个行为切片遵循红—绿—重构；全量测试、类型检查和每个云函数构建通过，且没有私密配置进入版本控制。
