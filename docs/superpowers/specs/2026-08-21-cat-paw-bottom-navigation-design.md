# 猫爪底部导航设计

## 目标

让用户在任何主页面都能一眼知道当前位置，并能清楚地在今日、历史和我的之间切换。设置不再是顶级导航项，而是“我的”内的二级入口。

## 信息架构

底部主导航固定为三个顶级目的地：

1. 今日：`pages/today/index`
2. 历史：`pages/history/index`
3. 我的：`pages/profile/index`

`pages/settings/index` 保持独立页面，承载 AI 说明、隐私说明和删除账户；从“我的”页的“设置与说明”入口进入。它不再出现在底部导航中。

目标拆解页 `pages/goal/index` 仍是临时流程。它保留三项主导航和“正在制定：目标拆解”路径标签；点击其他主目的地前，若有未确认内容，继续显示现有离开确认。

## 视觉与交互

底栏使用同一套线条猫爪图标和文字标签，不使用 emoji、网络图标或第三方字体。

- 每项包含猫爪图标和文字，触控高度至少 88rpx。
- 当前项使用深青色圆角胶囊，内部为浅色文字和金色填充猫爪；同时通过形状、文字权重和颜色表达选中状态。
- 非当前项使用暖灰色线条猫爪与文字，保持足够对比度。
- 按下反馈仅改变不透明度和背景色，时长不超过 200ms，不改变布局。
- 底栏继续处理底部安全区；各页面保留足够的底部内容空间，避免被导航遮挡。

## 实现边界

- 继续使用现有自定义 tabBar 和共享 `bottom-navigation` 组件。
- 将共享组件的数据源改为三个主目的地；选中态依据当前路由计算。
- “我的”页增加通往设置页的普通页面入口；不迁移或改变删除账户的逻辑。
- 不修改云函数、数据模型、计划与目标流程语义。

## 验收

1. 今日、历史、我的的当前项均有猫爪图标、文字和高对比胶囊状态。
2. 三项均可正确切换到对应页面，设置不再出现在底栏。
3. 我的页可进入设置页；设置页可返回我的页且不显示底栏。
4. 目标拆解页显示三项主导航和“正在制定：目标拆解”路径标签；离开未确认内容仍需要确认。
5. 375px 宽度下无文字截断，安全区和页面内容不重叠。
6. 自动测试、TypeScript 类型检查和 `git diff --check` 通过。
