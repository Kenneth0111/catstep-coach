# 奶金猫爪导航与按钮垂直居中设计

## 目标

- 任务卡中的难度选择按钮和“缩小任务”等次要按钮，文字在按钮内垂直、水平居中。
- 底部导航移除三个常驻的文字上方猫爪图标。
- 仅当前页显示 D2“奶金猫爪”：连续猫爪外轮廓、四颗趾垫和一块大掌垫；当前页文字位于大掌垫内。
- 未选中导航项只显示文字，不出现猫爪，也不因其他导航项的按压状态改变。

## 视觉结构

猫爪采用已经确认的 D2 方案：奶油白外壳、暖棕金轮廓、奶金色趾垫和掌垫。图形略微倾斜，保持软萌印章感。猫爪以本地透明 PNG 资源呈现，当前页文字由 WXML 单独叠放，因此“今日 / 历史 / 我的”可以复用同一个图形资源。

底部导航继续使用现有安全区和固定定位逻辑，不改变路由、草稿拦截或三个入口。当前导航按钮本身不再使用整块深绿色背景，避免猫爪外形被遮没。

## 交互与可访问性

- 每个导航按钮保留 `aria-current`，并补充明确的 `aria-label`。
- 点击态只作用于被点击的导航按钮，不改变兄弟按钮。
- 猫爪图形只作为当前态视觉标记，导航文字仍是实际文本。
- 任务卡按钮继续保持不小于现有触控高度，使用弹性布局居中文本。

## 验收标准

- 任务卡难度按钮和次要按钮包含 `display: flex`、`align-items: center`、`justify-content: center` 与 `box-sizing: border-box`。
- 导航模板中不存在旧的 `active-mark`、`paw-icon`、`paw-toe`、`paw-pad` 结构。
- 仅活动项渲染 `nav-paw`，文字位于猫爪掌垫区域；非活动项仅渲染普通文字。
- 奶金猫爪透明 PNG 存在且由导航组件引用。
- 聚焦测试、全量测试、类型检查和 `git diff --check` 通过。
