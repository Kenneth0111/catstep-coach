# CatstepCoach 成长角色素材包与成长页设计

## 目标

把当前“我的”页由合规说明页调整为以小橘陪伴和正向成长为核心的个人成长页。用户可看到自己的累计成长值、等级与当前状态；隐私和数据删除保留为次要设置入口。

## 范围

### 角色素材

产出同一原创手绘小橘角色的 12 张独立透明 PNG。所有素材保持橘猫、青绿色外套、橙色围巾、纸张与手绘铅笔质感；不新增另一套角色画风。

| 类别 | 素材 |
| --- | --- |
| 等级基础姿态 | Lv.1 起步伙伴、Lv.2 灵感观察员、Lv.3 稳定行动家 |
| 通用状态 | 欢迎、专注、完成任务、连续行动、暂停后回来、升级庆祝 |
| 轻动画帧 | 眨眼、挥爪、轻跳 |

“暂停后回来”表现为安静等待和欢迎，不表现失落、扣分或惩罚。动画只使用短暂、可停止的微动；页面不使用无限循环的大幅动画。

### 成长页

采用“每日伙伴 + 成长旅程”的组合布局：顶部显示当前等级的小橘与鼓励语，中部显示累计成长值和距离下一等级的进度，再展示最近已确认复盘获得的成长记录；底部折叠或跳转至提醒、隐私与数据删除。

三级规则沿用既有产品设计，不另造等级体系：

- Lv.1 起步伙伴：0–99 点。
- Lv.2 灵感观察员：100–249 点。
- Lv.3 稳定行动家：250 点及以上。

成长页只显示服务端真实持久化的累计成长值和最近已确认复盘的成长记录。新增受认证的成长摘要接口只读取当前可信微信身份的 `users.growth` 与最多三条 `reviews` 的 `date`、`growthAwarded`；不返回复盘正文、OpenID、文档 ID 或请求 ID。连续行动天数和累计完成数在没有经过认证的统计接口前不得显示为真实数字，也不得用演示值替代。

## 状态映射

优先级从高到低：刚完成复盘或升级时显示庆祝；有进行中任务时显示专注；当天有完成任务时显示完成任务；首次进入显示欢迎；其它时候显示等级基础姿态。用户从中断后返回时一次性显示“暂停后回来”，随后回到基础姿态。

## 技术边界

- 素材存放在小程序静态资源目录，页面只通过本地路径加载；不从客户端上传或生成图片。
- 角色选择为纯函数：输入真实成长值与页面状态，输出素材路径和无障碍替代文字。
- 成长值与等级计算为纯函数，边界值 99、100、249、250 必须自动测试。
- 若需要新增个人成长读取云函数，它只从可信 `WX_OPENID` 读取当前用户的 `users.growth`；客户端不能传入用户身份或成长值。
- 删除账户后，成长页读取到空档案时显示新用户欢迎状态，不缓存或展示已删除数值。

## 验收与测试

1. 12 张素材存在、尺寸一致、文件不含用户数据。
2. 等级边界和状态优先级均由纯函数测试覆盖。
3. 页面只显示经过认证读取的累计成长值；加载、未认证、空档案与错误状态具有稳定文案。
4. 角色图片有替代文字；减少动态效果设置下不自动播放动画。
5. 隐私与删除入口仍可访问，删除确认和既有删除行为不变。
6. 全量测试、类型检查及受影响云函数构建通过。

## 非目标

- 不新增虚假的连续天数、累计完成数或排行榜。
- 不改变成长值的既有写入规则、每日上限或账户删除边界。
- 不实现付费装扮、社交分享、抽卡或随机奖励。
