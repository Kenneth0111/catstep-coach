# CatstepCoach 猫系交互音效设计

## 目标

采用用户在仓库根目录 `sound_effects/` 提供的五段最终 MP3，为现有四类语义交互加入可爱、活泼的卡通音效。保留现有共享播放模块、静音设置、冷却防叠加和失败降级逻辑，不在小程序运行时请求任何第三方服务。

## 音效分类

| 类别 | 最终素材 | 播放规则 |
| --- | --- | --- |
| `tap` | `tap.mp3` | 导航、筛选和普通轻触固定播放该素材 |
| `action` | `action.mp3` | 新建、调整、确认等明确操作固定播放该素材 |
| `success` | `success.mp3` | 完成任务、保存成功等正向结果固定播放该素材 |
| `cat` | `cat1.mp3`、`cat2.mp3` | 每次通过冷却检查的猫猫点击按次交替播放两段素材 |

## 素材约束

- 五段素材均为用户提供的最终声音，不再通过 ElevenLabs 生成候选。
- 素材保持 MPEG-1 Layer III、48 kHz、192 kbps MP3 原格式，避免额外转码损失和系统级音频工具依赖。
- `tap.mp3`、`action.mp3`、`cat2.mp3` 各约 1.06 秒；`success.mp3`、`cat1.mp3` 各约 2.06 秒。
- 五段素材总体积约 171 KiB，复制到 `miniprogram/assets/sounds/` 后作为本地静态资源离线播放。
- 仓库根目录的 `sound_effects/` 作为用户原始素材目录完整保留。

## 实现边界

- `SoundEffect` 仍只有 `tap`、`action`、`success` 和 `cat` 四个语义类别。
- `sound-effects.ts` 统一维护语义类别到本地资源列表的映射；页面和组件不直接管理文件名或音频上下文。
- 单素材类别始终使用同一路径；`cat` 使用确定性的轮换，不使用随机数。
- 只有播放实际执行成功后才推进 `cat` 轮换索引；被冷却、静音或播放失败的尝试不推进。
- 保持设置页音效开关、全局与单类冷却、播放失败不影响主流程的行为。
- 删除不再被引用的旧 WAV 占位素材和候选生成脚本，但不修改或回退 Today UI、AI 运行时配置及其他用户改动。

## 验收标准

- 所有现有按钮触发位置继续使用原有四个语义类别。
- 猫猫点击在 `cat1.mp3` 与 `cat2.mp3` 间稳定交替，快速重复点击仍受冷却保护。
- 五段 MP3 均有有效 MPEG 音频帧，时长不超过 2.2 秒，合计不超过 180 KiB。
- 音频关闭或播放失败不影响任何主要交互。
- 相关测试、完整测试、类型检查、相关构建和 `git diff --check` 全部通过。
- 不提交、不推送、不部署。
