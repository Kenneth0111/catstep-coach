# 猫步计划 Catstep Coach

> 一只温暖、敏锐的好奇学霸猫，陪你把学习和工作目标变成今天真正能完成的一小步。

![好奇学霸猫角色概念](docs/superpowers/specs/assets/curious-scholar-cat-handdrawn-v1.png)

## 项目简介

猫步计划是一款面向普通用户的 AI 教练型微信小程序。它围绕长期目标、当天状态和历史执行情况，与用户共同确认每日行动，并通过温和提醒、任务缩小、晚间复盘和伙伴成长，帮助用户形成稳定习惯。

项目首先以免费微信小程序 MVP 验证完整闭环，后续计划扩展商业版与 Android App。

## 核心体验

- 目标澄清：AI 通过有限追问，把模糊目标整理为可确认的结构化目标。
- 主动计划：结合长期目标、可用时间、精力和历史反馈，推荐 1–5 个具体任务。
- 逐级督促：先温和提醒，再询问阻碍，最后缩小任务或重新排期。
- 轻量反馈：一键完成，并记录“轻松 / 刚好 / 困难”和一句感受。
- 晚间复盘：总结执行情况，给出次日起步建议，并由用户确认长期记忆。
- 正向成长：任务、反馈和复盘转化为猫伙伴成长值，中断不惩罚。

## 产品原则

- AI 负责推荐，用户拥有最终决定权。
- 先给出具体下一步，再提供情绪支持。
- 关键节点短对话，不做无限自由聊天。
- AI 不可用时，任务管理与复盘仍然可用。
- 不以断签、降级或负面话术制造焦虑。

## 技术方案

```text
原生微信小程序 + TypeScript
  -> CloudBase Node.js 云函数
      -> 目标与计划服务
      -> 执行、复盘与成长服务
      -> 提醒、额度与日志服务
      -> AIProvider
          -> 腾讯 TokenHub / 已备案文本模型
      -> CloudBase 文档数据库与云存储
```

AI 能力拆分为 `clarifyGoal`、`generateDailyPlan`、`resizeTask` 和 `generateReview` 四个独立工作流。模型输出经过 Schema、时长、目标归属和安全校验；超时或输出异常时自动降级为规则模板。

## MVP 验收重点

- 5 分钟内完成首次目标澄清并获得本人确认的计划。
- AI 任务包含具体动作、预计时长和完成标准，且不超出可用时间。
- 计划、执行、反馈、复盘和成长闭环可在体验版走通。
- 模型失败、网络失败和额度耗尽都有可用降级路径。
- 用户数据按微信身份隔离，并支持实际删除。
- 至少 30 个脱敏案例通过结构校验与人工质量评测。

## 路线图

1. 免费微信小程序 MVP：完成体验版、测试、评测与审核提交。
2. 商业小程序：在主体条件具备后加入会员、支付和趋势分析。
3. Android App：增加持续通知、桌面组件、离线能力与跨端账号。
